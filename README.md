# Campus Fresh Zone

## 프로젝트 소개

Campus Fresh Zone은 캠퍼스 내 환경 데이터를 기반으로 사용자에게 야외활동 가능 여부와 대응 솔루션을 제공하는 서비스이다.

온도, 습도, 공기질, TVOC, eCO2 등의 환경 데이터를 활용하여 현재 환경 상태를 판단하고, 정상 / 주의 / 위험 단계에 따라 사용자에게 적절한 안내 메시지를 제공한다.

아래 내용은 수월한 개발을 위해 작성한 내용으로 편의에 따라 언제든 변경될 수 있음.

---

## 주요 기능

- 캠퍼스 환경 데이터 조회
- 온도, 습도, 공기질, TVOC, eCO2 정보 표시
- 정상 / 주의 / 위험 단계 분류
- 환경 상태에 따른 야외활동 솔루션 제공
- 앱과 서버 간 REST API 연동
- 기준 기반 위험도 판단 로직 적용

## 판단 기준

본 서비스는 공식적인 법적 측정·판정 시스템이 아니라, 공공기관 기준을 참고하여 위험 가능성을 사용자에게 안내하는 모니터링 및 의사결정 보조 서비스이다.

| 항목 | 정상 | 주의 | 위험 | 참고 기준 |
|---|---|---|---|---|
| AQI / CAI | 0~50 | 51~100 | 101 이상 | 에어코리아 통합대기환경지수 |
| eCO2 / CO2 | 1000ppm 이하 | 1001~1500ppm | 1501ppm 이상 | 실내공기질 관리법, 학교보건법 |
| TVOC | 400㎍/㎥ 이하 | 401~500㎍/㎥ | 501㎍/㎥ 이상 | 실내공기질 권고기준 |
| 온도 | 24~26℃ | 27~32℃ | 33℃ 이상 | 질병관리청, 기상청 폭염특보 기준 |
| 습도 | 적정 범위 | 고습 / 저습 | 고온과 결합 시 위험 가중 | 온열질환 예방 기준 |

## 솔루션 제공 방식

서버는 수집된 환경 데이터를 기준표와 비교하여 현재 상태를 정상 / 주의 / 위험 단계로 분류한다.

이후 초과 항목에 따라 사용자에게 적절한 대응 메시지를 제공한다.

| 조건 | 판단 | 제공 솔루션 |
|---|---|---|
| AQI / CAI 101 이상 | 공기질 나쁨 | 야외활동 자제 및 마스크 착용 권장 |
| CO2 1000ppm 초과 | 환기 부족 가능성 | 실내 공간 환기 권장 |
| TVOC 500㎍/㎥ 초과 | 유기화합물 농도 높음 | 오염원 확인 및 접근 주의 |
| 온도 33℃ 이상 | 온열질환 위험 | 야외활동 자제, 수분 섭취, 휴식 권장 |
| 고온 + 고습 | 체감온도 상승 가능 | 장시간 야외활동 자제 권장 |

## 개발 규칙

### Branch Rule

- `main`: 최종 안정 버전
- `develop`: 개발 통합 브랜치
- `feature/*`: 기능 개발 브랜치

예시:

```text
feature/android-ui
feature/server-api
feature/risk-logic
feature/docs
```

### Commit Rule

커밋 메시지는 아래 형식을 사용합니다.

| 태그 | 의미 |
|---|---|
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| docs | 문서 수정 |
| design | UI 디자인 수정 |
| refactor | 코드 구조 개선 |
| chore | 설정 및 기타 작업 |

예시:

```text
docs: README 초안 작성
feat: 센서 데이터 모델 추가
feat: 위험도 판단 로직 구현
fix: API 응답 파싱 오류 수정
design: 센서 카드 UI 수정
```

## 프로젝트 목표

Campus Fresh Zone은 캠퍼스 환경 데이터를 활용하여 사용자가 현재 야외활동 환경을 쉽게 파악하고, 위험 상황에서 적절한 행동을 선택할 수 있도록 돕는 것을 목표로 한다.
